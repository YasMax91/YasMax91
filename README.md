wrong — payments and clearing, order lifecycles, production floors. Six years, mostly PHP and
Laravel, mostly domains that punish guesswork.

**[Groundwork](https://github.com/YasMax91/groundwork)** — my open-source (MIT) Claude Code plugin
for spec-driven development: risk-based task classification L0–L4, five specialised review agents,
eleven automated gates that must be green before anything is called done. Adopted across 7
production codebases; roughly **one task in three is stopped before any code is written** — because
it was mis-scoped, conflicted with existing behaviour, or was cheaper to solve without development.
